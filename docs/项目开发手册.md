# 实飞单机控制开发手册（Odin + exp_single）

面向二次开发：在 **Odin 定位 + PX4/MAVROS +** `exp_single_uav_control_fsm.launch` 链路下，如何理解状态机、发控制指令、以及调参。

默认机号 `uav_id=1`，命名空间 `/uav1`。下文话题均按此书写。

---

## 1. 启动链路

按顺序启动：

```bash
# 启动 ros 主节点
roscore
# 启动 odin 定位程序
cd ~/Odin_ws/ && source devel/setup.bash && roslaunch odin_ros_driver odin1_ros1.launch
# 启动 mavros
cd ~/agile_ws/ && source devel/setup.bash && roslaunch uav_control_fsm px4.launch
# 启动 uav_control_fsm 主节点
cd ~/agile_ws/ && source devel/setup.bash && roslaunch uav_control_fsm exp_single_uav_control_fsm.launch
# 启动 ego 避障
cd ~/agile_ws/ && source devel/setup.bash && roslaunch ego_planner exp_single_planner.launch
```


| 层                                   | 作用                                                                                       |
| ----------------------------------- | ---------------------------------------------------------------------------------------- |
| Odin                                | 外部视觉/惯导定位，输出里程计                                                                          |
| `px4.launch`                        | MAVROS ↔ 飞控（默认 `/dev/ttyACM0:921600`，命名空间 `/uav1`）                                       |
| `exp_single_uav_control_fsm.launch` | 透传实飞参数，include `uav_control_fsm_unit.launch` 起 FSM; 封装控制接口，统一使用/uav1/move_command控制无人机运动 |


**数据流：**

```
Odin 里程计
  → (launch remap) /uav1/odin_odometry
  → OdometryBridge → /uav1/mavros/vision_pose/pose
  → PX4 EKF

上层任务 / planner
  → /uav1/move_command
  → ControlFSM + ControlManager
  → /uav1/mavros/setpoint_raw/local
```

FSM 自身用的反馈位姿来自 `/uav1/mavros/local_position/odom`（飞控融合后的本地里程计）。

## 2. Odin 对接要点（必做）

`OdometryBridge` 在定位源为 `Odin` 时订阅：

```text
/uav1/odin_odometry   (nav_msgs/Odometry)
```

并转发到：

```text
/uav1/mavros/vision_pose/pose   (geometry_msgs/PoseStamped)
```



### 2.1 配置定位源

编辑 `config/uav_group.yaml`：

```yaml
default_location_source: Odin
```

`Odin` profile 会写入（启动且 MANUAL、未解锁时）：

- `EKF2_AID_MASK: 24`（视觉 + 外部导航）
- `EKF2_HGT_MODE: 3`（Vision）
- 以及 `px4_params_common` 中的速度/围栏等公共项

真机 `no_RC:=false` 时，若参数有变更会触发飞控 reboot；参数已匹配则跳过。

### 2.2 配置 remap

Odin 实飞需改成把 **Odin 实际输出话题** remap 到 bridge 期望的 `odin_odometry`。

示例（按 Odin 驱动真实话题名改 `odom_remap_to_topic`）：

```bash
roslaunch uav_control_fsm exp_single_uav_control_fsm.launch \
  odom_remap_topic:=odin_odometry \
  odom_remap_to_topic:=<Odin实际里程计后缀>
```

含义：节点侧订阅名 `odin_odometry`，被 remap 到 `/uav1/<Odin实际里程计后缀>`。

也可直接改 launch 默认值，避免每次命令行传入。

### 2.3 启动后自检

```bash
rostopic echo /uav1/mavros/vision_pose/pose
rostopic echo /uav1/mavros/state
```

关注 `connected` 应为 `True`。

## 3. 启动后实际跑什么

`exp_single` → `uav_control_fsm_unit.launch`，在 `/uav1` 下：


| 组件                   | 说明                               |
| -------------------- | -------------------------------- |
| 节点 `uav_control_fsm` | 主状态机 + setpoint 发布               |
| 内部 `OdometryBridge`  | Odin → vision_pose               |
| 内部 `ControlManager`  | `Move_mode` → `PositionTarget`   |
| 内部 `ArmAndOffboard`  | 解锁 / 切 OFFBOARD / AUTO.LAND      |
| 内部 `TFManager`       | `world → uav1_map → base_link` 等 |


主循环（`uav_control_fsm_node.cpp`）：

```text
spinOnce → process() → publishFsmState() → [OFFBOARD 时] publishSetpoint()
```

默认 `loop_hz=30`。

## 4. 状态机



### 4.1 状态定义


| 层级  | 枚举              | 含义                                    |
| --- | --------------- | ------------------------------------- |
| 主状态 | `MANUAL_CTRL`   | 不发 Offboard setpoint；可 RC 手飞 / POSCTL |
| 主状态 | `OFFBOARD_CTRL` | 持续发 setpoint，并请求解锁+OFFBOARD           |
| 子状态 | `AUTO_TAKEOFF`  | 爬升到 `takeoff_height`（或当前高度更大者）        |
| 子状态 | `AUTO_HOVER`    | 锁当前悬停点                                |
| 子状态 | `CMD_CTRL`      | 执行最近一次合法的 `move_command`              |


降落不走子状态：收到 `/land_command` 后直接切 PX4 `AUTO.LAND`，FSM 回到 `MANUAL_CTRL`。

### 4.2 常用转移

```text
MANUAL_CTRL
  ├─ RC 通道6 高档 / offboard_command=true
  │     且 FCU 已连接、odom 有效
  │     ├─ 已在空中解锁 → OFFBOARD / AUTO_HOVER
  │     └─ 地面 / 未在空 → OFFBOARD / AUTO_TAKEOFF
  │           到达高度 → AUTO_HOVER
  └─ (其他) 保持手动

AUTO_HOVER
  ├─ 有新鲜指令且 PX4 已是 OFFBOARD → CMD_CTRL
  ├─ RC 中档 / odom 超时 / RC 超时 → MANUAL（POSCTL）
  └─ hover_command → 刷新悬停点，保持 HOVER

CMD_CTRL
  ├─ 速度/轨迹类指令超时 → AUTO_HOVER
  ├─ 位置类(0/1，含5/6转世界后) 到达 → AUTO_HOVER（指令可超时仍锁存）
  ├─ 非法指令 / 严重超限 → AUTO_HOVER
  └─ odom/RC 超时 → MANUAL

任意 OFFBOARD
  ├─ RC 中档 → MANUAL / POSCTL
  ├─ 飞控/QGC 主动退出 OFFBOARD → FSM 同步 MANUAL（不再自动拉回）
  └─ land_command → PX4 AUTO.LAND + MANUAL
        （拨杆须离开高档，否则可能拒降 / 被再次拉回 Offboard）
```



### 4.3 RC Offboard 三档（真机默认通道 6）


| 档位  | 归一化约值                    | 行为                   |
| --- | ------------------------ | -------------------- |
| 高档  | `norm > 0.3`（约 PWM>1650） | 进入 Offboard          |
| 中档  | `-0.3 ≤ norm ≤ 0.3`      | 退出 Offboard → POSCTL |
| 低档  | `norm < -0.3`            | 保持当前遥控器预设的状态         |


`exp_single` 默认：`rc_offboard_channel:=6`。

## 5. 控制接口



### 5.1 话题一览


| 话题                                | 类型                              | 方向  | 说明                              |
| --------------------------------- | ------------------------------- | --- | ------------------------------- |
| `/uav1/move_command`              | `uav_control_fsm/uav_command`   | 入   | 主控制指令                           |
| `/uav1/offboard_command`          | `std_msgs/Bool`                 | 入   | `true` 请求进 Offboard（等同 RC 高档逻辑） |
| `/uav1/hover_command`             | `std_msgs/Bool`                 | 入   | `true`：Offboard 下切悬停并刷新悬停点      |
| `/uav1/land_command`              | `std_msgs/Bool`                 | 入   | `true`：请求 AUTO.LAND             |
| `/uav1/set_location_source`       | `std_msgs/String`               | 入   | 如 `"Odin"`；仅 MANUAL 且未解锁        |
| `/uav1/control_fsm/state`         | `uav_control_fsm/uav_fsm_state` | 出   | 统一状态（与 `loop_hz` 同频）            |
| `/uav1/mavros/setpoint_raw/local` | `mavros_msgs/PositionTarget`    | 出   | Offboard setpoint               |
| `/uav1/mavros/vision_pose/pose`   | `geometry_msgs/PoseStamped`     | 出   | 外部位姿给 EKF                       |


坐标系约定：指令与本地里程计按 **ENU** 理解（`pos_ref` 米；`yaw_ref` / `yaw_rate_ref` 为 **度 / 度每秒**）。

### 5.2 `uav_command` 与 Move_mode


| Move_mode | 含义                               |
| --------- | -------------------------------- |
| 0         | 惯性系 位置 + 偏航角（可开软件平滑）             |
| 1         | 惯性系 位置 + 偏航角速度（到达后可绕自身转）         |
| 2         | 惯性系 速度 + 偏航角                     |
| 3         | 惯性系 速度 + 偏航角速度                   |
| 4         | 惯性系 定高 + 水平速度 + 偏航角              |
| 5         | 机体系 位置 + 偏航角（入队时一次性转到惯性系 mode 0） |
| 6         | 机体系 位置 + 偏航角速度（入队时转到惯性系 mode 1）  |
| 7         | 机体系 速度 + 偏航角                     |
| 8         | 机体系 速度 + 偏航角速度                   |
| 9         | 机体系 定高速度 + 偏航角                   |
| 10        | 轨迹：位置 + 速度 + 加速度 + yaw           |


字段：

- `pos_ref` / `vel_ref` / `acc_ref`：`geometry_msgs/Point`
- `yaw_ref`：期望偏航，**度**
- `yaw_rate_ref`：期望偏航角速度，**度/秒**
- `header.stamp`：建议填当前时间；过期会被丢弃（见限幅）



### 5.3 指令生命周期

1. **校验**（`validateAndSanitizeMoveCommand`）
  - stamp 过期（默认 `max_age_sec=0.5`）→ **丢弃**，不切悬停  
  - `Move_mode>10` / NaN/Inf / 高度窗外 → **拒绝并 AUTO_HOVER**  
  - 速度/加速度/偏航速：超限但未达 `severe_ratio` → soft clamp；超过 `limit * severe_ratio` → 拒绝并悬停
2. **mode 5/6** 在回调里一次性转到世界系 0/1，避免每帧重算相对位移。
3. **CMD_CTRL 超时策略**
  - 位置锁存：mode 0/1（及已转换的 5/6）——指令可超时，仍跟踪目标直到 `arrival_dist`  
  - 速度/轨迹：超时 `cmd_timeout_sec`（默认 0.5 s）→ AUTO_HOVER



### 5.4 发布示例

悬停后飞到惯性系点 `(1, 0, 1.2)`，航向 0°：

```bash
rostopic pub -1 /uav1/move_command uav_control_fsm/uav_command \
"{header: {stamp: now}, Move_mode: 0,
  pos_ref: {x: 1.0, y: 0.0, z: 1.2},
  vel_ref: {x: 0, y: 0, z: 0},
  acc_ref: {x: 0, y: 0, z: 0},
  yaw_ref: 0.0, yaw_rate_ref: 0.0}"
```

机体前向速度 0.5 m/s：

```bash
rostopic pub /uav1/move_command uav_control_fsm/uav_command -r 20 \
"{header: {stamp: now}, Move_mode: 7,
  pos_ref: {x: 0, y: 0, z: 0},
  vel_ref: {x: 0.5, y: 0, z: 0},
  acc_ref: {x: 0, y: 0, z: 0},
  yaw_ref: 0.0, yaw_rate_ref: 0.0}"
```

速度类建议以高于 `1/cmd_timeout_sec` 的频率持续发布。

## 6. 调参手册



### 6.1 Launch（`exp_single_uav_control_fsm.launch`）


| 参数                            | 默认（实飞）              | 说明                          |
| ----------------------------- | ------------------- | --------------------------- |
| `uav_id`                      | 1                   | 命名空间 `/uavX`                |
| `no_RC`                       | false               | 真机有遥控；影响 RC 订阅与是否 reboot 写参 |
| `loop_hz`                     | 30                  | FSM 主循环 Hz                  |
| `takeoff_height`              | 1.0                 | 自动起飞目标高度 m                  |
| `cmd_timeout_sec`             | 0.5                 | 速度/轨迹指令超时回悬停                |
| `odom_timeout_sec`            | 1.0                 | 里程计超时退 MANUAL               |
| `vision_pose_pub_rate_hz`     | 0.0                 | 0=跟 Odin 同频；>0 定时重复发最新位姿    |
| `pos_smooth_enable`           | true                | Move_mode=0 软件平滑            |
| `enable_odom_remap`           | true                | 是否 remap 外部里程计              |
| `odom_remap_topic`            | 需改为 `odin_odometry` | bridge 侧话题名                 |
| `odom_remap_to_topic`         | 填 Odin 输出后缀         | 真实里程计话题                     |
| `rc_offboard_channel`         | 6                   | Offboard 拨杆通道               |
| `rc_offboard_enter_threshold` | 0.3                 | 高档进入                        |
| `rc_offboard_exit_threshold`  | -0.3                | 中档退出下沿                      |


`px4.launch` 常用：`fcu_url`（串口）、`gcs_url`（QGC）、`tgt_system`（须与 PX4 `MAV_SYS_ID` 一致，单机一般为 1）。

### 6.2 `config/uav_group.yaml`


| 项                                      | 作用                                                 |
| -------------------------------------- | -------------------------------------------------- |
| `default_location_source`              | 启动默认定位源 → 设为 `Odin`                                |
| `px4_params_common.MPC_XY_VEL_MAX` 等   | 飞控速度限幅；同时派生指令 `max_xy_velocity` / `max_z_velocity` |
| `GF_MAX_HOR_DIST` / `GF_MAX_VER_DIST`  | 地理围栏                                               |
| `location_profiles.Odin`               | EKF 视觉融合相关参数                                       |
| `command_limits.max_xy_acceleration` 等 | FSM 侧指令检查                                          |
| `command_limits.min_z` / `max_z`       | 位置类高度窗（ENU）                                        |
| `command_limits.max_age_sec`           | 指令 stamp 最大年龄                                      |
| `command_limits.severe_ratio`          | 超限判定严重倍数                                           |


速度/偏航限幅不单独再写一份：由 PX4 参数与当前定位源的 `MC_YAWRATE_MAX` 派生。

### 6.3 `config/pos_smooth_param.yaml`（仅 Move_mode=0）


| 参数                          | 默认   | 说明           |
| --------------------------- | ---- | ------------ |
| `pos_smooth_max_vel`        | 1.0  | 巡航速度 m/s     |
| `pos_smooth_max_accel`      | 1.2  | 制动曲线加速度 m/s² |
| `pos_smooth_arrival_dist`   | 0.1  | 到达距离 m       |
| `pos_smooth_lookahead_dist` | 0.5  | 前视距离 m       |
| `pos_smooth_vel_deadband`   | 0.05 | 末端速度死区       |


关闭平滑：`pos_smooth_enable:=false`（变回位置阶跃跟踪）。

### 6.4 运行时切换定位源

```bash
rostopic pub -1 /uav1/set_location_source std_msgs/String "data: 'Odin'"
```

条件：FSM 为 `MANUAL_CTRL` 且未解锁。会切换 bridge 订阅，并按需写 PX4 参数（真机可能 reboot）。

## 7. 实飞操作简流

1. 上电飞控与板载机，启动 roscore → Odin → `px4.launch` → `exp_single`。
2. 确认 MAVROS `connected`，vision_pose / odom 频率正常，`location_source=Odin`。
3. RC 安全通道可用；Offboard 拨杆在低/中档。
4. 拨杆高档（或发 `offboard_command`）→ 自动起飞至 `takeoff_height` → `AUTO_HOVER`。
5. 需要暂停：发 `hover_command` 或停发速度指令等超时回悬停。
6. 降落：拨杆离开高档后发 `land_command`（或 RC 中档退 Offboard 后手降）。

## 8. 调试清单


| 现象                 | 排查                                                                        |
| ------------------ | ------------------------------------------------------------------------- |
| `odom_valid=false` | Odin 是否在发；remap 是否指到 `odin_odometry`；`default_location_source` 是否为 `Odin` |
| 无法进 Offboard       | FCU 未连、odom 超时、起飞间隔过短、当前不在 MANUAL/HOVER                                   |
| 指令无响应              | 看是否在 `CMD_CTRL`、指令是否过期/被拒                                                 |
| 速度模式突然悬停           | `cmd_timeout_sec`：提高发布频率或加大超时                                             |
| 位置冲过头              | 开平滑并降 `pos_smooth_max_vel` / `max_accel`                                  |
| land 后立刻又起飞        | Offboard 拨杆仍在高档；先拨离高档                                                     |
| 参数改完不生效            | 真机写参可能 reboot；确认服务 `/uav1/mavros/param/set` 可用                            |


常用命令：

```bash
rostopic echo /uav1/mavros/state
rostopic hz /uav1/mavros/vision_pose/pose
rostopic echo /uav1/mavros/setpoint_raw/local
```

## 10. 发布 ego_planner 目标点

需已启动：

```bash
roslaunch ego_planner exp_single_planner.launch
```

默认 `flight_type:=1`（手动目标）时，规划器订阅：

| 项 | 值 |
|----|-----|
| 话题 | `/uav{uav_id}/goal_point`（单机默认 `/uav1/goal_point`） |
| 类型 | `quadrotor_msgs/GoalSet` |
| 字段 | `float32[3] goal`（ENU，单位 m：x, y, z） |

约束：`goal[2]` 必须 **大于** 规划 launch 中的 `virtual_ground`（`exp_single_planner` 默认 `-2.0`），否则会被拒绝。

发布示例（飞到 `(2, 0, 1.2)`）：

```bash
rostopic pub -1 /uav1/goal_point quadrotor_msgs/GoalSet \
"{goal: [2.0, 0.0, 1.2]}"
```

说明：规划器收到目标后自行规划，并通过 `/uav1/move_command` 等接口驱动控制 FSM；上层一般只需发目标点，不必直接拼轨迹 setpoint。
/uav{uav_id}/goal_point
