# 大模型无人机台架链路：自启动与验收

本套脚本沿用现有 NX、Odin、ROS Noetic、MAVROS、PX4、4090 模型环境。当前验证范围是拆桨固定台架。**不能据此认定已经能够自主飞到椅子、避障或降落。**

## 1. 连接方式

按现场要求继续用 Mac 中转：

```text
NX 相机 + Odin/MAVROS 位姿
 → NX vla_direct_bridge.py
 → NX 127.0.0.1:15017
 → Mac SSH 中转
 → 4090 127.0.0.1:5007/predict
 → 真实模型 action/action_ori
 → 坐标核算、时间与步长检查
 → /vla/validated_prediction
 → 显式台架测试脚本限幅
 → /uav1/move_command
 → 保护分支 FSM
 → /uav1/mavros/setpoint_raw/local
 → PX4 控制器与电机输出
```

NX：`nvidia@192.168.1.108`；4090：`howard@39.105.30.146:7027`。Mac 必须开机、登录、不休眠，且同时能到达两台机器；NX 当前不能直连公网服务器。15017 仅监听回环地址。旧的 15007 通道不再被新脚本使用。

## 2. 日常启动

NX 用户 cron 已配置开机延迟 20 秒启动，不需要打开桌面终端。Mac 登录任务 `com.agile.vla-tunnel` 负责转发、SSH 断线重连，每约 30 秒检查 4090 推理服务；模型不在运行时使用既有 openvla 环境加载模型，加载期间不重复拉起进程。

在 NX 终端手动运行：

```bash
cd /home/nvidia/agile
./vla_start.sh
./vla_status.sh
```

启动包含 ROS master、Odin、MAVROS、保护 FSM、模型预览桥接、只读网页、当前轮次报告发布。无需原来的五个终端标签。再次执行 start 会复用现有监督进程；发现其他 ROS master 时拒绝启动第二套。请勿同时运行旧的 `start_uav.sh` 或旧桥接启动器。

默认 `bench_disarmed=true`、`bench_allow_armed=false`、桥接 `enable_publish=false`。**启动不会请求 OFFBOARD、解锁或自动起飞。** FSM 会发送当前位姿保持 setpoint，模型仅生成候选与通过检查的预测。`ready=true` 表示新鲜的图像/位姿/推理校验链路可用，不代表解锁检查或飞行验收通过。

状态和日志：`/home/nvidia/agile/runtime/vla/`。主要文件：`status.json`、`supervisor.log`、`odin.log`、`mavros.log`、`fsm.log`、`bridge.log`、`monitor.log`、`boot.log`。

网页：[http://192.168.1.108:8088/](http://192.168.1.108:8088/)。页面只读显示链路；人工“电机启动/停转”按钮只是记录观察，不会控制电机。

## 3. 未解锁完整验收

保持拆桨、固定，开启遥控器，油门最低，CH9 解锁开关低位，先保持 MANUAL。运行：

```bash
cd /home/nvidia/agile
./vla_test.sh
```

依次进行 9 项坐标数学测试、4 项上锁收尾测试、9 项真实话题诊断和 8 次真实模型目标传递。诊断会请求未解锁 OFFBOARD，结束后恢复原模式；不会请求解锁。脚本等待新鲜有效模型结果，超时或任何断言失败即失败，不会放宽检查以凑通过。

诊断目标用于测控制路径，与模型目标分开记录。模型目标严格使用当前轮次、当前指令、当前时间戳，通过额外台架限幅：XY≤5cm、Z≤1cm、yaw≤3°。结果写入 `diagnostic_report.json`、`model_report.json`、`acceptance.json`，页面第15、16项同步显示。同一时刻只允许一个验收流程。

## 4. 显式短时电机验收

仅适用于**已拆桨、机身固定**的台架。开启遥控器，保持油门最低、CH9低位、MANUAL或已确认的未解锁OFFBOARD；准备好遥控器停机。执行：

```bash
cd /home/nvidia/agile
./vla_motor_test.sh --props-removed --fixed
```

脚本临时接管 FSM，启用受租约约束的 armed 台架分支，启动独立看门狗。先进入 OFFBOARD 并核对真实模型点在未解锁时已传至 MAVROS，随后通过正常解锁服务尝试约 5 秒测试。每次模型目标再限制为 XY≤2cm、Z≤3mm、yaw≤1°。模型过期、状态不符或模式变化会结束测试。成功时上锁后保持 OFFBOARD，总时长约30秒，再恢复 MANUAL，并恢复 `bench_allow_armed=false` 的默认控制器。

看门狗限制解锁窗口；FSM 租约最新心跳须在0.25秒内、总长最多10秒。普通上锁被拒绝且仍解锁时，仅在上述明确拆桨固定参数下允许强制**上锁**收尾（MAV_CMD_COMPONENT_ARM_DISARM，param1=0，param2=21196）；没有强制解锁，也没有绕过 PX4 解锁检查。不得在带桨或空中使用这套台架收尾。

结果：`motor_report.json`、`motor_wrapper_cleanup.json`、`watchdog_report.json`、`motor_fsm.log`、`motor_watchdog.log`，页面第17项。测试通过表示模型限幅目标已进入控制链，最终上锁有遥测证明；如果没有 ESC RPM 样本，实际电机转动仍须现场观察。请只在本次确实看到后点击页面的人工确认按钮。

## 5. 停止与修改指令

```bash
cd /home/nvidia/agile
./vla_stop.sh
```

停止前必须能读取到已连接、未解锁的飞控状态；不满足条件时拒绝停止，避免直接拆掉控制链。只停止本套监督进程拥有的进程组。若电机仍在转，先用遥控器完成上锁，再核对 `armed=false`。

默认中文指令为“飞到椅子上”。需要改指令时，先停止，在 `/home/nvidia/agile/vla_config.json` 修改 `instruction`，然后启动并重新验收。桥接每次重启都会生成新 `run_id`、重新建立任务起点；旧轮次报告不会当作新轮次通过。

## 6. Mac 运行目录与维护

Mac 程序和受限连接密钥：`~/Library/Application Support/AgileVLA/`；登录项：`~/Library/LaunchAgents/com.agile.vla-tunnel.plist`。使用 Application Support，避免登录任务无法读取 Documents 的系统隐私限制。运行密钥只用于受限转发/服务器推理检查；私钥不包含在交付压缩包中。

在 Mac 终端检查或重新加载：

```bash
launchctl print gui/$(id -u)/com.agile.vla-tunnel
cat "$HOME/Library/Application Support/AgileVLA/state/status.json"
cat "$HOME/Library/Application Support/AgileVLA/state/inference_guard.txt"
launchctl kickstart -k gui/$(id -u)/com.agile.vla-tunnel
```

`running` 只表示 SSH 进程存活，最终以 NX 看到新鲜推理结果为准。SSH 日志在该目录 `state/gpu.log`、`state/uav.log`，后台错误在 `launchagent.log`。NX 未开机时转发会等待重连。Mac 休眠期间推理不可用；不会将旧模型点当成新结果继续测试。

4090 检查脚本：`/home/howard/UAV-Flow/.vla-service/ensure_inference.sh`；日志：同目录 `inference.log`。已有服务正常时不重启或改变模型。当前 GPU 服务没有在本次测试中强行终止重载，避免影响已经加载的模型。

## 8. 已知边界与排障

- `rc receiver: Fail`、RC通道无消息：先恢复遥控器连接。实测此状态下 OFFBOARD 请求可显示已发送，但遥测仍是 MANUAL；不得当作进入成功。
- `prediction rejected`：真实模型可能给出越界 Z 或 yaw，当前候选限值 XY≤0.35m、Z≤0.05m、yaw≤8°。保持保护，检查画面、任务提示和训练分布，不能将 HTTP 成功等同模型具备可靠导航能力。
- 服务器输出为第一帧任务坐标 cm/rad，输入本体状态 cm/deg；桥接换为 m/rad，FSM指令 yaw 使用 deg，MAVROS setpoint yaw 使用 rad。Odin→MAVROS 为同步位姿配对估算，尚无经过物理标定的固定变换。
- 直接模型链路未接入 EGO 障碍物规划、椅子到达判定或自主降落逻辑。固定台架不会产生飞行位置变化，不能验收“动作改变位置→新观测→纠偏→到达”的真实导航闭环。
- 桥接/网页进程退出会由 NX 监督器重启；MAVROS自身launch配置允许节点重启。ROS master或整个监督器异常退出后应检查日志并人工重新启动；本脚本不在飞控解锁时自动重建控制器。
- NX 开机入口与 Mac 登录入口已配置；实际断电重启、Mac 注销登录后的完整恢复需要现场另行验收。本次以停止全部软件、重新启动进行验证，不能替代电源循环试验。

## 9. 重装与取消自启

交付目录包含现有环境所需脚本、保护 FSM 头文件与验收程序。传到 NX 后运行 `bash install_nx_autostart.sh`，会备份原说明/配置，必要时编译 FSM，并保留用户其他 cron 项。它针对当前已有工作区，不负责全新操作系统的 ROS、Odin 驱动或模型依赖安装。

取消 NX 自启动：使用 `crontab -e` 删除带 `# agile-vla-autostart` 的那一行。取消 Mac 登录任务：`launchctl bootout gui/$(id -u)/com.agile.vla-tunnel` 后移除对应 plist。需要彻底撤销连接时，再从两台服务器 `~/.ssh/authorized_keys` 中删除注释为 `agile-vla-autostart-20261010` 的专用公钥行，不要删除其他登录密钥。

原使用说明备份：`/home/nvidia/agile/runtime/vla/backups/使用说明.before_autostart.md`。本轮实测结果见同目录 `验收结果.md`，其中保留失败尝试及其原因。
